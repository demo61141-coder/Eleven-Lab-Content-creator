# কিকি বিগ রিরেকর্ড সাবটাইটেল

যেকোনো স্ক্রিপ্ট → কিকি বিগ রিরেকর্ড কণ্ঠের অডিও + সময় মিলিয়ে সাবটাইটেল (SRT / JSON)।

কিকি বিগ রিরেকর্ড মডেল = নতুন কণ্ঠে KIKI HASAN Big স্ক্রিপ্ট পড়া (১,৬৪১ ক্লিপ /
২২০.০ মিনিট), EMTIAZZ বেস থেকে নতুন করে ~৮০ এপক ট্রেনিং (পরিকল্পিত ৯০-এর
মধ্যে বাকি ১০ এপিক ব্যবহারকারীর সিদ্ধান্তে বাদ — ৮০ এপকের কণ্ঠ ভালো লেগেছে);
চেকপয়েন্ট checkpoint_15500 (step ১৫,৫০০)।

এটা আলাদা নতুন কণ্ঠ — কিকি, রাকিব বা আকিব কারও সঙ্গে মেশানো হয়নি; স্ক্রিপ্ট
একই, কণ্ঠ আলাদা মানুষের।

তিনটি পথ:
- **A. স্ক্রিপ্ট → অডিও + সাবটাইটেল (সবচেয়ে নির্ভুল):** প্রতি বাক্য আলাদা করে বানানো হয়, প্রতিটার আসল সময় মেপে SRT/JSON বানানো হয়।
- **B. অডিও + স্ক্রিপ্ট → সাবটাইটেল:** আগে বানানো কিকি বিগ রিরেকর্ড অডিও আপলোড করুন আর স্ক্রিপ্ট দিন — অডিওর নীরবতা ধরে বাক্যের সীমানা মেলানো হয়।
- **C. স্ক্রিপ্ট + মোট সময় → সাবটাইটেল (আনুমানিক):** মোট সময় দিলে বাক্যের দৈর্ঘ্য অনুযায়ী ভাগ করে দেওয়া হয়।

## বিশেষ নোট — বানানরীতি

এই মডেল কিকি বানানরীতি ব্যবহার করে (য়→য+়, ড়→ড+়, ঢ়→ঢ+়)। অডিও বানানোর
সময় লেখা নিজে নিজে normalize করা হয় — সাবটাইটেলে আপনার মূল স্ক্রিপ্টের
লেখাই থাকে, তাই পড়তে কোনো সমস্যা হয় না।

ASR (অডিও শুনে লেখা বের করা) কোথাও ব্যবহার করা হয় না — লেখা সবসময় আপনার
স্ক্রিপ্টেরটাই থাকে, তাই বাংলা ১০০% সঠিক।

## ফাইল

- `app.py` — Streamlit UI (বাংলা)
- `subtitle_tools.py` — বাক্য ভাগ, নীরবতা ধরে সীমানা, SRT/JSON, আনুমানিক ভাগ
- `tts_engine.py` — কিকি বিগ রিরেকর্ড TTS ইঞ্জিন (sherpa-onnx; মডেল HF থেকে নামে, MD5 মিলিয়ে)
